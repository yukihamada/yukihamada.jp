土曜日。bim.house と MU、それぞれ別のプロダクトなのに、今日やったことを並べてみたら同じ顔をしていた。**「言葉から始まって、誰かに届くまで」を1日で詰める**、という顔。

盛らずに、デプロイ済みのものだけ書く。「できた」は本番URLとセットで。

---

## bim.house — 言葉が、本当に建った

### SUUMOの売地100件に、家を建てた

「弟子屈に平屋を」と打てば3秒で家が出る、というデモはもう何度も見せた。今日やったのはその逆で、**実在する売地100件**（SUUMO 10都市ぶん）を引っぱってきて、その敷地条件で自動設計をぶん回した。

うれしいのは数字より中身で、**建築基準法チェック（houki）が本番で100/100 PASS**した。敷地いっぱいまで攻めても、斜線・軒の後退・28条ただし書きまで通る。「とりあえず四角い箱」じゃなく、ちゃんとその土地に合法に建つ家が100棟。

### 麻布台ヒルズを、丸ごと持った

実験で、麻布台ヒルズを bim.json でモデル化して公開した（`u-azabudaihills`）。座標規約（最小コーナーmm基準）も部屋データもDB直で整えた。「言葉から建つ」エンジンが、**実在の巨大建築をどこまで飲めるか**の踏み込み。まだ粗いところはあるけど、丸ごと一棟を器に乗せられたのは大きい。

### ビューワーが、書類を7枚めくれるようになった

これが地味だけど一番効くやつ。3Dモデルを見るだけだったビューワーに、**概要カルテ / プレゼン / 図面 / 申請書類 / 見積 / 履歴 / JSON の7タブ**を足した。家を「眺める」から「読む」へ。英語環境では全UIが英語になる（辞書400語＋DOM監視で後追い翻訳）。北海道でもモロッコでも、と言ってる以上ここは譲れない。

ついでに、ずっと気持ち悪かった**白飛び（bloom過多）を根治**して、コマンドバーを v274 に。headless検証はMetal GPUじゃないと再現しないのが今日のハマりどころだった。

### 地味だけど大事な日

ほかにも今日は、製品BoMの自動配置＋金額同期、物件ステージの5段ラダー、確認申請の法域別フォーマット、Pro(¥980)と写真生成の課金E2E ── と、**「絵」を「事業」に変える配管**を何本も通した。家を建てるのは楽しい。建てた家でちゃんとお金が回るようにするのは、もっと大事。

## MU — 服は、出会いで育つ

### まず、謝った

楽しい話の前に。発送が漏れていた注文が2件あって、今日**救済発注を入れて、お礼を4通送った**（最後の送信判断は人がやる）。盛らないと決めている以上、恥もそのまま書く。気づいたら直す、気づかせてくれた人にはちゃんと謝る。それだけ。

### 応援Tの、最初の¥7,700

「衝撃波」── 京一郎を応援するTシャツ（名前もUFCも使わない、波だけのデザイン）の WAVE I が、**最初の¥7,700を売り上げた**。糸（ITO、服がウォレットになる仕組み）も今日で89粒に育った。たった¥7,700。でも0と1の差はいつも一番でかい。

### NOUNS のオーナーページを出した

Noun を持っている人が、自分のNoun IDからグッズに辿れる `/nouns` ページを本番に出した。暗号決済も自前ポーリングで通した。MUの「服が出会いで育つ」を、別のコミュニティの文脈に差し込んでみる実験。

### 作る人が、いなかった理由

正直な反省も。一般クリエイターの作成が実質ゼロだった真因は、**`/make`（作るページ）への流入がそもそもゼロ**だったこと。今日、広告の着地を3面用意して、成功体験ページ `/success` にCTAを置いた。蛇口が閉まってたら、いくら中をいじっても水は出ない。

そして裏では、MUのSEOを67点から95点まで引き上げた（英訳1036件＋6時間ごとのcron）。世界中で使われるサービスにする、と言ってる以上、まず見つけてもらえないと話にならない。

## 並べて見えたこと

bim.house は「言葉 → 図面 → 合法な建築 → 見積もり」、MU は「デザイン → 服 → 出会い → 糸」。
どっちも、**最初の一言から、誰かの手に届くまでの距離を、今日また少し縮めた**。

東京の100人じゃなく、世界の100万人に届くか。毎日その物差しで測る。今日の100棟と¥7,700は、その途中の薪。
